# MNIST Handwritten Digit Recognition

## 📌 Overview

A Deep Learning project that uses the **MNIST dataset** to recognize handwritten digits from **0–9** using a Neural Network built with **TensorFlow/Keras**.

## 🛠️ Technologies

* Python
* TensorFlow / Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## 🔄 Workflow

**Data Loading → Preprocessing → Model Building → Training → Evaluation → Digit Prediction**

## 🧠 Model

* Input: 784 features (28×28 images)
* Hidden Layers: Dense layers with ReLU
* Output: 10 classes with Softmax
* Optimizer: SGD
* Loss: Categorical Crossentropy

## 📊 Results

The experiments achieved approximately **97%+ validation accuracy**.
